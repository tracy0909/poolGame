# Pool Game – Unity3D 撞球遊戲

使用 **Unity C#** 製作的 3D 撞球遊戲，
玩家透過鍵盤與滑鼠控制母球方向與發射力道，模擬撞球操作體驗。

---

## 專案簡介

以 Unity3D 引擎開發，實作撞球的基本物理效果與互動操作，
透過鍵盤控制母球移動方向，搭配滑鼠設定發射角度與力量，
讓使用者能體驗簡易且直覺的撞球遊戲。

---

## 技術棧

| 類型          | 技術                         |
| ----------- | -------------------------- |
| Game Engine | Unity3D                    |
| Language    | C#                         |
| Physics     | Unity Rigidbody / Collider |
| Platform    | Windows                    |

---

## 操作方式

| 操作      | 功能       |
| ------- | -------- |
| ↑ ↓ ← → | 控制母球移動方向 |
| 滑鼠左鍵    | 調整母球發射方向 |
| 滑鼠右鍵    | 發射母球     |
| 右側力量圈   | 顯示目前發射力道 |

---

## 遊戲特色說明

* 直覺式撞球操作
* Unity 物理引擎模擬撞擊效果
* 鍵盤 + 滑鼠雙重操控模式
* 即時顯示擊球力量

---

## 專案目的

* Unity3D 基本操作與場景管理
* Rigidbody / Collider 物理互動
* 3D 遊戲物件控制與輸入事件處理能力
